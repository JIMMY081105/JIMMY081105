### 🔬 Current Research

**Simulation-ready scene generation for humanoid training**

I am developing pipelines that transform generated indoor environments into robust training scenes through:

`Scene Generation → Geometry QA → Collision Validation → Multi-floor Assembly → Simulation-ready Export`

The work combines scene reasoning, automated quality gates, HPC pipelines, rendering, benchmarking, and robotics-oriented environment design.
